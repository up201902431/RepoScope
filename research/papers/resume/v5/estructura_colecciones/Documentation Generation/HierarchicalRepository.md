# Hierarchical Repository-Level Code Summarization — resumen

- **Tarea:** resumen de código Java jerárquico desde entidades hasta archivos/paquetes.
- **Aporte:** AST para segmentar funciones, variables, constructores, enums e interfaces; LLM locales resumen unidades y agregan niveles; prompts incorporan dominio y contexto de negocio.
- **Evaluación reportada:** BSS de telecomunicaciones; por restricciones de propiedad intelectual presenta evaluación de un repositorio público descrito como similar. Reporta mejoras de cobertura con segmentación y relevancia con grounding de negocio.
- **Límite:** dominio de negocio y Java; no evidencia selección de documentos ni generación de funciones.
- **Relación con tesis:** antecedente de resúmenes derivados del código y generación jerárquica; mantener separado de documentación enlazada a APIs.
- **Evidencia:** §§I–III, pp. físicas 1–4; §IV, p. 5; §V, Tablas III–VII, pp. 6–7.
- **Cobertura:** método y resultados analizados; referencias y metadatos formales pendientes.

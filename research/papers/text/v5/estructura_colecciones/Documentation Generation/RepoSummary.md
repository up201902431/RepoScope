# RepoSummary — registro de la fuente en Documentation Generation

La copia local `reposummary.pdf` corresponde a *RepoSummary: Feature-Oriented Summarization and Documentation Generation for Code Repositories*, arXiv:2510.11039v1 (13 de octubre de 2025); no se incluirá en el commit. El [registro arXiv](https://arxiv.org/abs/2510.11039v1), sus metadatos, autores, método, evaluación y límites constan en la [ficha canónica existente](../../../../resume/v5/estructura_colecciones/Documentation-Code/fourth/repoSummary.md); se evita duplicarla.

## Alcance de esta copia local

- **Autores según el PDF:** Yifeng Zhu, Xianlin Zhao, Xutian Li, Yanzhen Zou, Haizhuo Yuan, Yue Wang y Bing Xie.
- **Paginación:** 22 páginas físicas.
- **Cobertura de la ficha canónica:** lectura analítica focalizada en §§1, 3–6 y evaluación (pp. físicas 2–19); no afirma revisión exhaustiva de todas las secciones.
- **Imagen:** el flujo ya está representado en [pipeline.svg](../../../../images/v5/estructura_colecciones/Documentation-Code/fourth/repoSummary/pipeline.svg) y su [versión PNG](../../../../images/v5/estructura_colecciones/Documentation-Code/fourth/repoSummary/pipeline.png).

El método agrupa código alrededor de features y genera resúmenes de features/epics con enlaces a elementos de código; no es un sistema para seleccionar documentos de APIs según un requisito y alimentar con ellos un generador de funciones. Véase la ficha canónica para evidencia y localizadores.
